# site-theme-beta

Dark theme stylesheet.

Use this URL as the custom stylesheet:

```
https://cdn.jsdelivr.net/gh/teo0321/site-theme-beta@main/theme.css
```

jsDelivr caches `@main` for up to ~12 hours. For an instant update, tag a release
(`git tag v1.0.1 && git push --tags`) and point the URL at `@v1.0.1`, or purge the cache at
https://purge.jsdelivr.net/gh/teo0321/site-theme-beta@main/theme.css
